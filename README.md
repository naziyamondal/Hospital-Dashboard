# 🏥 Hospital Dashboard

## 📊 Project Overview

The Hospital Dashboard is an interactive data visualization project created to analyze and present hospital-related data in a simple and understandable format.

The dashboard provides a visual summary of important hospital information using charts, graphs, KPI cards, and interactive filters.

## 🎯 Project Objectives

* Analyze hospital data using data visualization techniques.
* Create an interactive and user-friendly dashboard.
* Monitor important hospital-related KPIs.
* Identify trends and patterns in the data.
* Present complex data in a simple visual format.
* Support data-driven decision-making.

## 🛠️ Tools & Technologies Used

* Microsoft Excel
* Excel Pivot Tables
* Pivot Charts
* Slicers and Filters
* Data Cleaning
* Data Analysis
* Data Visualization
